# موقع المطعم - دليل الاستخدام

موقع ثابت (HTML/CSS/JS) بدون أي سيرفر أو قواعد بيانات. الألوان: أسود وأحمر وأبيض.

## الملفات
- `index.html` — واجهة الموقع للزبائن (القائمة، البحث، السلة، تحديد الموقع، إرسال واتساب)
- `admin.html` — لوحة التحكم (إضافة/تعديل/حذف الوجبات والأقسام، الإعدادات)
- `shared.js` — البيانات الافتراضية ودوال مشتركة
- `app.js` — منطق واجهة الزبون
- `admin.js` — منطق لوحة التحكم
- `style.css` — التنسيق (أسود / أحمر / أبيض)

## كيف يعمل
- كل البيانات (الوجبات، الأقسام، الإعدادات) تُخزَّن في متصفح المتجر (localStorage) عند استخدام لوحة التحكم.
- كلمة مرور لوحة التحكم الافتراضية: `1234` — غيّرها فوراً من تبويب "الإعدادات".
- زر "إرسال الطلب عبر واتساب" يفتح محادثة واتساب جاهزة برسالة فيها: الوجبات والكميات والمجموع، اسم الزبون، رقم هاتفه، ورابط موقعه على خرائط جوجل (إن حدده).
- رقم واتساب المطعم يُضبط من لوحة التحكم > الإعدادات (اكتبه بصيغة دولية بدون + مثل 9647700000000).

## التشغيل محلياً
افتح `index.html` مباشرة بالمتصفح، أو شغّل خادماً محلياً بسيطاً داخل مجلد `restaurant-site`:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080/index.html` و `http://localhost:8080/admin.html`.

## النشر لجميع الزبائن (مهم)
التعديلات التي تضيفها في لوحة التحكم تُخزَّن فقط في متصفحك (localStorage) ولا تظهر تلقائياً للزبائن الآخرين. لنشرها لكل من يزور الموقع:

1. من لوحة التحكم > الإعدادات > اضغط "تصدير data.json".
2. ضع الملف الناتج `data.json` داخل نفس مجلد `index.html` على الاستضافة (أي مجلد `restaurant-site`).
3. ارفع المجلد كاملاً (أو حدّث `data.json` فقط) إلى الاستضافة (مثل GitHub Pages، Netlify، Vercel، أو أي استضافة ثابتة).
4. في كل مرة تعدّل القائمة من لوحة التحكم، كرر خطوتي التصدير والرفع لتحديث الموقع للجميع.

> ملاحظة: عند فتح الموقع بصيغة `file://` مباشرة (بدون خادم) لن يستطيع المتصفح قراءة `data.json` تلقائياً بسبب قيود الأمان؛ استخدم خادماً محلياً كما بالأعلى أو استضافة حقيقية.

## النشر المجاني السريع
- **GitHub Pages**: ارفع مجلد `restaurant-site` إلى مستودع GitHub وفعّل Pages من إعدادات المستودع.
- **Netlify / Vercel**: اسحب مجلد `restaurant-site` وأفلته في لوحة Netlify Drop، أو اربطه بمستودع Git.

## التخصيص
- الشعار واسم المطعم: من لوحة التحكم > الإعدادات.
- الألوان: عدّل المتغيرات في بداية `style.css` (`--red`, `--black`, `--white`).
- صور الوجبات: ترفعها من لوحة التحكم (تُحفظ داخل البيانات نفسها بعد ضغطها تلقائياً).
